# JoodBlmojood

A web-based cooking platform that helps users discover recipes based on available ingredients.

## Features

- Browse and search recipes
- Search by ingredients
- Add and share recipes
- User registration and login
- Rate recipes

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
